# Jerry Nguyen - Data Scientist Portfolio

A concise, single-page portfolio focused on my experience in data science,
applied machine learning, analytics, and AI.

**Live site:** [anh-nguyenn.github.io](https://anh-nguyenn.github.io/)

## About

I am a Data Scientist at GlobalFoundries in Singapore. My work spans
semiconductor operations, machine learning, analytics, automation, and
production AI.

The portfolio presents selected experience and education in a minimal,
accessible, and responsive format.

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS
- GitHub Pages and GitHub Actions

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To create a production build:

```bash
npm run build
```

## Deployment

Pushes to `main` automatically build and deploy the static site through
[the GitHub Pages workflow](.github/workflows/deploy-pages.yml).
