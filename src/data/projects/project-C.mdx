# Auto-Email-Reply

## Project Overview

**NTU SimplifyNext RPA x GenAI Hackathon Project**  
**Duration**: January 2024 - March 2024

Developed a solution integrating Generative AI and RPA to streamline student administrative queries, reducing response times by 80%. Enhanced OpenAI GPT-3.5 with a retrieval-augmented generation (RAG) system for context-aware email automation and designed an NLP masking algorithm using spaCy to protect sensitive data during processing.

## Project Background

### Hackathon Context

- **Event**: NTU SimplifyNext RPA x GenAI Hackathon
- **Focus**: Automation and AI integration for administrative efficiency
- **Challenge**: Streamlining student administrative processes
- **Duration**: 3-month intensive development period

### Problem Statement

Student administrative offices face significant challenges:

- **High Volume**: Thousands of repetitive email queries daily
- **Slow Response Times**: Manual processing takes hours to days
- **Resource Intensive**: Administrative staff overwhelmed with routine tasks
- **Inconsistent Responses**: Human responses vary in quality and accuracy
- **Data Privacy Concerns**: Sensitive student information in emails

## Solution Architecture

### Core Components

#### 1. Generative AI Integration

- **OpenAI GPT-3.5**: Primary language model for email generation
- **Retrieval-Augmented Generation (RAG)**: Context-aware response generation
- **Fine-tuning**: Custom training for administrative domain knowledge
- **Response Templates**: Structured email templates for consistency

#### 2. RPA (Robotic Process Automation)

- **Email Monitoring**: Automated email inbox scanning
- **Query Classification**: Intelligent categorization of student requests
- **Response Automation**: Automated email composition and sending
- **Workflow Integration**: Seamless integration with existing systems

#### 3. NLP Data Protection

- **spaCy Integration**: Advanced natural language processing
- **Masking Algorithm**: Sensitive data protection during processing
- **Privacy Compliance**: GDPR and data protection standards
- **Audit Trail**: Complete processing logs for compliance
