Large Language Models (LLMs) have demonstrated remarkable language understanding and generation capabilities but often suffer from hallucinations and lack of interpretability. To address these issues, we present a framework that integrates LLMs with Knowledge Graphs (KGs) to improve the accuracy and explainability of the facts. This paper introduces a multistage architecture and a fine-tuning pipeline for SPARQL query generation.

Compared to existing LLM baselines, our approach achieves more reliable factual grounding and provides clearer explanations through structured KG reasoning.

### Research Contributions

- Novel framework for LLM-KG integration
- Fine-tuning pipeline for SPARQL query generation
- Comprehensive evaluation methodology
- Open-source implementation for the research community
