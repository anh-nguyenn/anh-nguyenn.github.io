# Shopee Card

## Project Overview

Shopee Card is a new attractive way of contactless payment in Singapore designed specifically for millennials and Gen Z. This innovative payment solution combines modern design with cutting-edge technology to create a seamless and engaging payment experience.

## Key Features

- **Contactless Payment**: Modern NFC technology for quick transactions
- **Millennial & Gen Z Focus**: Designed for younger demographics
- **Singapore Market**: Tailored for the Singaporean payment ecosystem
- **Mobile Integration**: Seamless connection with mobile apps
- **User Experience**: Intuitive and attractive interface design
