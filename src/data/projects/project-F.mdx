# NTU Thinking & Communicating Visually courses

## Project Overview

These NTU courses focus on developing visual communication and design skills through different approaches. The courses include DA2002 (Thinking and Communicating Visually) for artistic expression and visual storytelling, and DA3000 (Autodesk Inventor) for technical design and 3D modeling capabilities.

## DA2002 - Thinking and Communicating Visually

DA2002 is an art class project that explores the intersection of visual communication, creative thinking, and design principles. This course demonstrates the power of visual storytelling and how effective communication can be achieved through thoughtful design and artistic expression. Through various assignments, class activities, and a final project, students develop their visual thinking and communication skills.

## DA3000 - Autodesk Inventor Project

DA3000 focuses on 3D modeling and engineering design using Autodesk Inventor. This comprehensive project required building everything using Autodesk Inventor software, conducting detailed analysis of existing clock designs, and applying our learning experience to design an entirely new clock for the final project. The course demonstrates proficiency in computer-aided design (CAD) and showcases the ability to create complex 3D models, perform engineering analysis, and develop innovative design solutions.
